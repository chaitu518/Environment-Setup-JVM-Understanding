
What is JDK, JRE, JVM:
JDK: jdk is used to develop java applications. It contains the JRE and development tools like compiler, debugger, etc.
JRE: jre is used to run java applications. It contains the JVM and libraries required to run java applications.
JVM: jvm is used to execute java bytecode. It is a virtual machine that runs on top of the operating system and provides a platform-independent environment for executing java applications. It also provides features like garbage collection, memory management, and security.

What is bytecode:
Bytecode: bytecode is the intermediate representation of java code that is generated by the java compiler. It is a platform-independent code that can be executed by the JVM on any operating system. The JVM translates the bytecode into machine code that can be executed by the underlying hardware.

What does “write once, run anywhere” mean (1–2 short paragraphs):
"Write once, run anywhere" is a slogan that describes the ability of Java applications to run on any platform without modification. 
This is achieved through the use of the Java Virtual Machine (JVM), which abstracts away the underlying hardware and operating system. 
When a Java program is compiled, it is converted into bytecode, which can be executed by any JVM regardless of the platform it is running on. 
This allows developers to write their code once and have it run on multiple platforms without needing to make any changes, making Java a popular choice for cross-platform development.
